# HexPanel Feed

قاعدة المحتوى بتاعة HexPanel: الإضافات والسكينات اللي بتظهر جوه البانل.
البانل بيقرا الملفات دي من لينكات raw، فأي تعديل هنا بيوصل للمستخدمين من غير نسخة جديدة من البلجن.

## التركيب

```
popular.json     إضافات قائمة "Popular plugins"
skins.json       سكينات قائمة "Community skins"
installers/      سكريبتات تثبيت صغيرة خاصة بينا (اختياري)
```

الملفات الكبيرة (ipk، سكينات مضغوطة) مش في الشجرة دي: بتترفع على
**Releases** من صفحة الريبو، ولينك الملف بيتحط في الـ JSON.

## شكل كل مدخل

```json
{
  "label": "اسم يظهر في القائمة",
  "url": "https://...  لينك سكريبت تثبيت .sh (بيتحمل ويتشغل)",
  "cmd": "أمر شيل بدل url لو محتاج",
  "note": "وصف صغير (اختياري)",
  "sha256": "بصمة الملف للتحقق قبل التشغيل (اختياري)",
  "novaler": true
}
```

- لازم `url` أو `cmd` على الأقل، غير كده المدخل مش هيظهر.
- `sha256` اختياري لكن مفضل لأي ملف على Releases: البانل هيتحقق منه قبل التشغيل.
- `novaler: true` يخلي المدخل يظهر على أجهزة Novaler بس.

## إضافة عنصر جديد

1. لو عندك ملف: اعمل Release جديد وارفع الملف، وخد لينكه.
2. افتح `popular.json` أو `skins.json` من هنا (قلم التعديل) وزود المدخل.
3. Commit. البانل هيلقط التغيير أول ما يتفتح.

## لينكات الـ raw اللي البانل بيستعملها

```
https://raw.githubusercontent.com/<اسم-حسابك>/hexpanel-feed/main/popular.json
https://raw.githubusercontent.com/<اسم-حسابك>/hexpanel-feed/main/skins.json
```
